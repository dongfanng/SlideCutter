核心痛点：现有工作流中，大模型生成的 PPT 素材为不可编辑的整张图片（含白色背景、多个离散图标/元素）。需手动经过“PS 去白底 → 切片工具切分 → magick mogrify 转换/去边”等多步操作，效率低下且重复性强。

项目目标：开发一个本地自动化工具，输入标准化白色背景的整张素材图，自动完成以下处理并输出单张透明 PNG 素材：

智能切片：识别图片内部的空白“河道”（垂直/水平间隔），自动切分每个独立子图。

格式转换：将非目标格式（如意外生成的 GIF）转为 PNG，保留透明通道。

自动裁切（Trim）：去除每张子图边缘多余的黑边或空白区域。

核心约束：

本地优先：全部处理在本地完成，确保 PPT 素材数据安全，不上传云端。

后续扩展性：后续可能迁移至浏览器端（纯前端 Canvas 实现）或边缘计算平台（如 Cloudflare Workers）。
